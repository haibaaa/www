Surge 2025 is the official website for the annual technical fest at Shiv Nadar Institute of Eminence. Built as a full-stack application with event management, registration system, and responsive design.

## features

- **Event listings** — comprehensive details about all competitions and activities
- **Registration system** — easy sign-ups for events with backend management
- **Real-time schedules** — live updates on fest timings and venues
- **Responsive design** — optimized for desktop and mobile devices

## role

Responsible for backend development, including API endpoints, database management, and registration logic. Collaborated with the frontend team to integrate the TypeScript-based client with the server.

## tech stack

- **TypeScript** — primary language
- **Node.js** — backend runtime
- **Responsive CSS** — mobile-first design
